# Reagent Examples

> **Config:** Resolve `{FORK_DIR}`, `{EDIT_MARKER}`, `{FORK_NAME}` from `.agents/fork-config.md`.

When adding a reagent:

- define reagent prototype under `{FORK_DIR}`;
- add localized name/description;
- define effects/conditions in data;
- avoid hardcoded reagent behavior in systems where reaction/effect data can express it.
